# 头条评论及正文提取器v1.0

一款用于提取今日头条文章正文及所有评论的浏览器插件，支持导出为CSV、DOCX、MD格式。

## 功能特点

- 提取今日头条文章的正文内容
- 提取文章的所有评论
- 支持导出为MD格式（默认）、CSV格式和DOCX格式
- 浮动窗口设计，点击即可开始抓取
- 玄幻科技风格界面，高端大气上档次

## 安装方法

1. 下载本项目的所有文件到本地
2. 打开浏览器的扩展管理页面（Chrome: chrome://extensions/）
3. 开启开发者模式
4. 点击"加载已解压的扩展程序"
5. 选择本项目的文件夹
6. 插件安装完成，会在浏览器右上角显示图标

## 使用方法

1. 打开今日头条文章页面
2. 点击浏览器右上角的插件图标
3. 在弹出的浮动窗口中点击"开始抓取并导出MD"按钮
4. 插件会自动提取文章正文和评论，并生成MD格式文件下载到本地
5. 文件名格式为：网页标题_正文及评论.md

## 技术实现

- 前端：HTML5 + CSS3 + JavaScript
- 浏览器API：Chrome Extensions API
- 功能模块：
  - 内容提取模块：提取文章正文和评论
  - 格式转换模块：生成MD、CSV、DOCX格式
  - 文件下载模块：将生成的文件下载到本地
